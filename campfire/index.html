Core loop

Tidak ada tutorial panjang. Tidak ada menu rumit. Kamu keluar, menebang pohon, membawa pulang kayu, dan berharap apinya cukup sampai matahari terbit.

Kumpulkan

Hutan memberi kayu, batu, dan resin. Setiap perjalanan punya risiko: makin jauh dari api, makin gelap jalannya.

  • Kayu bakar
  • Batu & flint
  • Resin untuk api panjang
02

Jaga Api

Api punya dua angka: panas dan bahan bakar. Keduanya turun terus. Kalau bahan bakar habis, dingin mulai masuk.

  • Isi ulang sebelum padam
  • Atur besar-kecil nyala
  • Bangun penahan angin
03

Bertahan

Malam ke-10 berbeda dari malam ke-1. Makhluk datang lebih cepat, suhu turun lebih dalam, dan kayu makin jauh.

  • Upgrade kapak & tempat berlindung
  • Simpan stok untuk malam badai
  • Kejar 99 malam

Token

$CAMPFIRE — untuk kosmetik, bukan untuk menang.

Game ini bisa dimainkan gratis sepenuhnya. Token hanya dipakai untuk hal yang tidak mengubah keseimbangan permainan: tampilan, kapasitas, dan konten musiman.

Yang bisa dibeli

  • Skin kapak & efek api
  • Slot inventory tambahan
  • Season pass & misi musiman
  • Emote & nama berwarna

Yang tidak dijual

  • Damage & HP ekstra
  • Kecepatan permanen
  • Kekebalan dari serangan
  • Apa pun yang membuatmu menang

Status

Token belum diterbitkan. Kontrak akan dibuat di jaringan Base dengan supply tetap, tanpa fungsi mint, dan tanpa owner — sehingga tidak ada yang bisa mencetak token baru atau mengubah aturan setelah peluncuran.

FAQ

Pertanyaan yang paling sering muncul.

Apakah harus beli token untuk main?

Tidak. Game bisa dimainkan gratis sepenuhnya. Token hanya untuk kosmetik dan kenyamanan.

Apakah ini game Play-to-Earn?

Bukan. Tidak ada janji penghasilan. Token bukan investasi dan tidak menjanjikan keuntungan apa pun.

Kapan token dirilis?

Setelah game bisa dimainkan. Token tanpa game hanya akan jadi token kosong, dan kami tidak mau itu.

Kenapa pakai Base?

Biaya transaksi sangat murah dan jaringan terhubung dengan ekosistem Ethereum, sehingga pembelian kosmetik tidak membebani pemain.

Apakah tersedia di Android?

Rencananya ya, setelah versi web stabil. Untuk sekarang fokus ke browser dulu.

Bagaimana kalau saya menemukan token bernama sama?

Abaikan. Hanya alamat kontrak yang dipublikasikan di halaman ini yang resmi.
